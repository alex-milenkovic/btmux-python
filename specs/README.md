# Structured source and scenario references

The CSV and JSON files here retain original C identities, source locations,
Python mappings, character definitions and executable acceptance manifests.
Initial/baseline disposition fields describe the original inventory; they are
not current completion claims. Runtime behavior is defined by the implementation
and exercised by the tests and scenario collections.

General source paths refer to the separately supplied `btmux/` checkout. The
six-location Aerospace profile uses the historical source described in the
[fighter guide](../docs/six-location-aerofighters-cli.md). Original source
comments, names and notices remain intact in those local reference checkouts.
